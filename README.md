# Lego-Dashboards-and-Visualization
An interactive LEGO Set Explorer dashboard designed to analyze and explore LEGO sets based on theme group, theme, age range, number of pieces, and price. The dashboard provides key insights such as average pieces and average price, while allowing users to filter and explore individual LEGO sets. 
## 📊 Dashboard Overview

The LEGO Set Explorer provides an easy way to discover LEGO sets and compare important information through an interactive dashboard.

### Key Information
- Average number of pieces
- Average LEGO set price
- Price range
- LEGO theme
- Age range
- Individual LEGO set details
- Year of release

## ✨ Features

- 🔍 **Set Explorer** – Explore different LEGO sets interactively.
- 🎨 **Theme Filtering** – Filter LEGO sets by theme group and theme.
- 👶 **Age Range Filtering** – View LEGO sets based on recommended age.
- 🧱 **Piece Analysis** – Compare the number of pieces in different sets.
- 💰 **Price Analysis** – Explore LEGO set prices and price ranges.
- 📌 **Selected Set Details** – View detailed information about a selected LEGO set.
- 📊 **Interactive Dashboard** – Easily navigate and filter the data.
